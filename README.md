# ربات خبرخوان تلگرام — نسخه Groq

این نسخه به جای OpenAI از Groq API استفاده می‌کند و برای اجرای روزانه می‌تواند با GitHub Actions اجرا شود؛ بنابراین برای شروع نیازی به خرید VPS نیست.

## اطلاعات محرمانه
این سه مقدار را فقط در GitHub Repository > Settings > Secrets and variables > Actions > New repository secret وارد کنید:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `GROQ_API_KEY`

هیچ‌کدام را در کد یا گفت‌وگو منتشر نکنید.

## زمان‌بندی
گزارش هر روز در 16:30 UTC اجرا می‌شود که برابر با 20:00 در تهران است. زمان‌بندی GitHub ممکن است چند دقیقه تأخیر داشته باشد. از تب Actions می‌توان اجرا را دستی هم آغاز کرد.

## مدل
مدل پیش‌فرض `openai/gpt-oss-20b` است. دسترسی، سهمیه و محدودیت‌های رایگان Groq تابع شرایط حساب و صفحه Limits آن است؛ رایگان بودن را تضمین نمی‌کند و در صورت اتمام سهمیه، اجرا ممکن است ناموفق شود.

## اجرای محلی آزمایشی
در محیطی که Python نصب است، متغیرهای بالا را تنظیم کنید و `RUN_ONCE=true` قرار دهید، سپس:
`pip install -r requirements.txt`
`python main.py`

## منابع و تنظیمات
منابع خبر در `feeds.json` هستند. گزارش فارسی، حداکثر ۲۰ خبر در ۲۴ ساعت اخیر را انتخاب می‌کند.
